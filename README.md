# ¿Se trata realmente de enseñar? · Equipo 8

Recurso hipermedial del Trabajo Práctico 4 de la **Maestría en Educación Virtual, Universidad de Nariño**, que toma como objeto de diseño la pista **D3.M4, «¿Se trata realmente de enseñar?»** de la Licenciatura en Educación Básica Primaria (modalidad virtual).

**Autores:** Luis Andrés Rodríguez Coral · Sandra Patricia Romero Fuertes · Juan Carlos Moreno Toledo · Leidy Yurani Escobar Martínez.

## Publicar con GitHub Pages

1. Inicia sesión en GitHub y crea un repositorio nuevo (por ejemplo, `equipo8-ensenar`). Selecciona **Public** si quieres una página pública.
2. Descarga y descomprime el ZIP. Sube **el contenido de esta carpeta** a la **raíz** del repositorio: `index.html`, `assets/`, `README.md` y `.nojekyll`. No subas únicamente `index.html`, porque perderías el diseño y el código de las actividades.
3. En el repositorio, abre **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**, rama `main` y carpeta `/(root)`. Guarda.
5. Cuando GitHub complete la publicación, abre la URL que aparezca en **Pages**. En un repositorio de proyecto suele tener la forma `https://USUARIO.github.io/NOMBRE-REPOSITORIO/`.
6. Para incorporarlo en Google Sites, usa **Insertar → Incorporar → URL** y pega la URL real de GitHub Pages. La posibilidad de embeber la página dependerá de las políticas de inserción del sitio. Como alternativa, agrega un botón con el enlace.

> Importante: este ZIP **no está publicado** automáticamente; es un paquete listo para subir. Antes de hacer público el repositorio, asegúrate de contar con autorización para compartir fotografías y nombres de los participantes.

## Componentes de la experiencia

- Cinco accesos académicos: plan curricular, informe TP4, planificación de la pista, Google Sites y defensa audiovisual.
- Cuatro nodos curriculares y evidencias propuestas E1–E4.
- Actividad de análisis de datos sobre residuos y una secuencia didáctica contextualizada.
- Desafío ramificado de tres decisiones con retroalimentación formativa.
- Bitácora de reflexión que puede copiarse o descargarse como `.txt`.
- Diseño accesible y adaptable a pantallas móviles.

## Alcance pedagógico y privacidad

Este recurso constituye **una propuesta formativa y de simulación**, no un informe de resultados empíricos de aprendizaje infantil. Las respuestas escritas se procesan en el navegador del visitante y **no se envían a un servidor ni se guardan en una base de datos**. Descarga o copia la bitácora antes de cerrar o recargar la página.

Las fuentes académicas y los documentos enlazados son externos; sus permisos de lectura dependen de cada servicio. El video también se abre en el sitio externo.
